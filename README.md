# DoodleWear

A full-stack Django-based e-commerce platform for custom apparel.

## Features
- User Authentication
- Product Catalog
- Shopping Cart
- Custom T-Shirt Design
- Razorpay Payment Integration
- Order Management
- Contact Form

## Tech Stack
- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Razorpay API
